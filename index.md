##### Project 2: Climate Change
*Collect historical temperature data for a location of interest and conduct a linear regression analysis to look for climate change indicators*


Death Valley National Park is known as one of the hottest places on earth. I also used to live in the California high desert not too far from it. The analysis of Death Valley National Park temperature data does show increasing temperature trends associated with climate change. What was more notable about this data set was that it showed how sensitive the data set is to the time of collection of the temperature measurements. A change to the temperature collection time in the middle of the data set caused a discontinuity in the temperature data that impacted the linear regression analysis. Analysis of minimum and maximum temperature data produced more consistent linear regression results and increasing temperature trends with similar, but not identical, growth slopes. See more details [here](climate_change.md).
